## About

I am an engineer by profession and a programmer by passion.

Although my professional career is not in software development, computers,
programming languages and technology have been a long-standing intellectual
interest of mine.

I enjoy exploring how different technologies work, why they make different
trade-offs, and what can be built with them.

My current areas of interest include:

- Rust
- Ruby & Ruby on Rails
- Python
- C#
- Linux
- CLI development
- Software architecture
- Developer tools
- Artificial intelligence
- Automation
- Data analysis

This website is a place to document what I learn, share ideas and showcase
projects I build along the way.

## What You'll Find Here

### Writing

I write about:

- Programming languages

- Linux

## Technology

The website itself is intentionally simple.

It is currently built using:

- HTML
- CSS
- JavaScript
- GitHub Pages

There is no backend and no database.

The aim is to keep the site fast, lightweight and easy to maintain.

---

## Philosophy

I believe that learning technology is more rewarding when you go beyond
using it and actually try to understand how it works.

> The most interesting part of technology is not memorising what already
> exists. It is understanding why it works, questioning its assumptions,
> and building something yourself.
